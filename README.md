# Nostalgic Baseball ⚾

昔のブラウザミニゲームのような、シンプルで気軽に遊べるタイミング野球ゲームです。

現在は「9回裏の大逆転劇」をテーマに、普通ならひっくり返せないような大差から、3アウトになるまでどこまで追い上げられるかを楽しむゲームになっています。

## 🎮 ブラウザで遊ぶ

**GitHub Pages:** https://masakiniwa.github.io/Nostalgic-Baseball/

インストール不要です。スマートフォン / PC のブラウザからそのまま遊べます。

## 遊び方

1. 「ゲーム開始」を押します。
2. 9回裏、**8〜12点ビハインド**からスタートします。
3. 投手の動きとボールを見て、振るか見送るかを判断します。
4. タイミングを合わせてヒットや長打を狙います。
5. ただし、芯を食っても野手の正面を突けばアウトになります。
6. 3アウトになるまでに、できるだけ点差を詰めます。
7. 相手の得点を上回れば、まさかの **逆転サヨナラ勝ち = GAME CLEAR** です。

サヨナラは簡単には起こりません。

このゲームでは、

- 何点返せたか
- 最終的に何点差まで迫れたか
- 同点まで追いつけたか
- ポイントをどこまで伸ばせたか
- 本当にサヨナラまでひっくり返せたか

という段階ごとの成果を楽しめます。

### ゲーム終了時の評価

| 評価 | 条件 | 追い上げボーナス |
|---|---|---|
| **GAME CLEAR / 伝説のサヨナラ** | 大差を本当に逆転 | — |
| **CLEAR目前 / 奇跡の同点** | 同点まで追いつく | +2,500 |
| **超猛追 / あと一打！** | あと1〜2点まで迫る | +1,200 |
| **猛追 / 射程圏まで来た** | あと3〜4点まで迫る | +700 |
| **大反撃 / 反撃成功** | 大きく点差を縮める | +350 |
| **NEXT CHALLENGE / 反撃終了** | 次の挑戦へ | — |

ポイント制と自己ベストもあるため、サヨナラできなくても毎回のプレイに記録が残ります。

## 操作方法

- スマートフォン: ゲーム画面をタップ、または「スイング！」ボタン
- PC: ゲーム画面をクリック、「スイング！」ボタン、または Space キー

画面下部の細いバーが**ミートポイント**です。マーカーの位置は打撃判定の座標そのものから描いているので、ここにボールが重なった瞬間が本当の芯です。

## 打撃判定

スイングの結果は、ミートポイントからのズレで決まります。

| ズレ | 結果 | 打席 |
|---|---|---|
| 最小（芯） | **ホームラン**、または伸びきらず **ツーベース** | 終了 |
| 小 | **ツーベース** | 終了 |
| 中 | **ヒット** | 終了 |
| 大 | **ファウル** | 続く |
| 特大 | **空振り**（ストライク） | 続く |

「惜しかった」ときほど打席が続くので、粘って次の球を待てます。

芯を食っても必ずスタンドインするわけではありません。投手が強いほど、会心の当たりが長打止まりになる確率も上がります。

### 凡打と併殺

**バットに当たっても、ヒットになるとは限りません。**

ヒットの帯に入っていても一定確率で野手の正面を突き、**凡打**になります。これは実際の野球の BABIP（インプレー打球が安打になる割合）と同じ役割で、この試合で打者がアウトになる主な原因です。

- 芯を食うほど正面を突く確率は下がります（完璧なタイミングは報われます）
- 一塁走者がいる状態で凡打になると、**併殺**の可能性があります
- 投手が強くなるほど、正面を突く確率も併殺率も上がります

「打った！」と思った直後にアウトが増える、少し理不尽な野球らしさです。

## カウントと見極め

ゲームにはボール / ストライク / アウトのカウントがあります。

- 振って大きく外す → 空振りストライク（打席は続く）
- 3ストライク → 三振で1アウト
- ボール球を見送る → ボール
- 4ボール → フォアボールで一塁へ（走者が詰まっていれば押し出し）

ボール球には2種類あります。

- **落ちる球**（フォーク / 消えるフォーク）: 打者の手前で大きく落ちる
- **抜ける球**（すっぽ抜け / 高め外し / ボール球）: 打者の手前で浮き上がる

どちらも振れば空振りストライク、見送ればボールです。ただし1打席はたいてい数球で決着するため、**四球までたどり着けるのは稀**です。出たらラッキーな払い戻し、くらいに考えてください。

球種は投球中には表示されず、投球結果が確定したあとに公開されます。

## 投手交代：先発 → 中継ぎ → FINAL BOSS

### 1. 先発投手

ゲーム開始時の投手です。ストレート、チェンジアップ、ツーシーム、カーブ、フォーク、すっぽ抜けを投げます。

### 2. 中継ぎエース

**3連打**するか、**4点**取ると先発はKO。中継ぎエースが登板し、難易度が一段上がります。

- 球速アップ
- スライダー追加
- ミート判定が狭くなる
- 正面を突く確率・併殺率アップ

### 3. FINAL BOSS 守護神

中継ぎエースを攻略し、本当に逆転が見えてくると登場します。目安は、

- 3点差以内まで迫る
- 塁上の走者を含めて同点圏が見える
- 大量点差から大きく追い上げる

といった状況です。守護神は完全なラスボスです。

- 160km級の剛速球
- 高速スライダー
- 消えるフォーク
- タイミングを崩す超遅球
- フォーク比率が高い
- ミート判定が極端に狭い
- 芯を食っても正面を突く確率が高い

「ここまで来たのに勝てない！」を狙った難易度です。

## 塁状況

ゲーム画面右上にダイヤモンド表示があり、一塁・二塁・三塁の走者を確認できます。

- ヒット: 走者が1つ進塁
- ツーベース: 走者が2つ進塁
- ホームラン: 全走者と打者が生還
- フォアボール: 必要な走者が押し出される
- 併殺: 一塁走者が消えて2アウト

満塁からの長打、押し出し、併殺、大量点差からの猛追など、短いプレイの中でも展開が変化します。

## 現在のバージョン: v0.6

v0.5 までは、バージョンごとに追加した JavaScript が前のバージョンの関数を上書きする構造でした。v0.6 では**投手ティア表による1ファイル構成**に作り直し、同時にバランスと操作性を調整しています。

### 構造の刷新

- `game.js` / `comeback-mode.js` / `v0.5-mode.js` の3ファイルを `game.js` 1つに統合
- 投手の強さ・球種・判定幅・運の重さは、すべて `TIERS` テーブルに集約
- 投手を増やすときは、テーブルに1行足すだけ（関数の上書きは不要）
- 可変な状態を1つのオブジェクトにまとめ、試合開始時に作り直す（リセット漏れが起きない）
- 到達不能になっていた166行を削除

### バランス

- 打撃判定を「本塁打 → 二塁打 → 単打 → ファウル → 空振り」に整理
- 凡打を距離ではなく運判定から発生させ、芯を食うほど報われるように
- 芯を食った打球を必ずホームランにせず、伸びきらない長打を混ぜた
- 先発KO条件に「4失点」を追加
- 守護神の登板タイミングを、本当に逆転が見える所まで引き付けた
- 球速上限を投手ごとに設定（設定した加速がそのまま効くようになった）
- 超遅球のテンポを改善
- 2ストライク後のファウル無限稼ぎを封じた（ポイント加算は3球目まで）

### 操作性・表示

- タイミングメーターを実際のミートポイントに一致させた
- 打者とボールの位置を全画面幅で統一（PCとスマホで芯の位置が変わらない）
- ボールの描画を `transform` に統一（毎フレームのレイアウト再計算をなくし、判定のブレを軽減）
- 横向き（landscape）でもスイングボタンが画面内に収まるように
- プレイ中の下スワイプによるページ再読み込みを抑止
- セーフエリア対応、`prefers-reduced-motion` 対応、フォーカス移動の整理

### 安定性

- `localStorage` が使えない環境（プライベートブラウズ等）でもゲームが起動する
- `AudioContext` の生成に失敗しても投球が止まらない
- 打球アニメーションを含む全アニメーションを確実に停止できるように
- 壊れたベストスコアで更新が止まる問題を修正
- タブを離れると一時停止し、戻ると投げ直しから再開

### そのほか（v0.5から継続）

- 9回裏・大逆転チャレンジ / 8〜12点ビハインドのランダムシナリオ
- サヨナラを真のゲームクリアとして扱う設計
- 同点 / 超猛追 / 猛追 / 大反撃などの追い上げ評価と追い上げボーナス
- ポイント / ベストスコア
- 一塁 / 二塁 / 三塁の走者管理
- 投球中の加速・減速・緩急変化 / 球種の事後表示
- 軽量な Web Audio 効果音
- 棒人間をベースにしたミニマルなビジュアル
- 外部ライブラリ不要 / サーバー不要

すべて静的ファイルで動作するため、GitHub Pagesだけで公開できます。

### 開発メモ

- **投手を追加・調整するとき**は `game.js` の `TIERS` を編集してください。球種表・判定幅・運の重さ・球速上限がすべてここにあります。
- **判定幅の数値**は「ミートポイントからの距離（フィールド幅を100とした値）」です。その投手の球速で割ると、そのままプレイヤーに許される入力猶予（ミリ秒）になります。
- **リリースするとき**は `index.html` の `?v=0.6` を上げてください。GitHub Pages のキャッシュ（`max-age=600`）で新旧のファイルが混ざるのを防ぎます。

## このゲームで目指しているもの

2000年代ごろによく見かけた、説明を読まなくてもすぐ遊べる小さなWebゲームの感覚を、現代のブラウザで気軽に楽しめる形にすることを目指しています。

複雑な操作よりも、

- ボールを見る
- 振るか見送るか一瞬で判断する
- タイミングを合わせる
- 当たったのにアウトになる
- 走者がたまって緊張感が増す
- 好調になると投手が強くなる
- 大量点差を少しずつ詰めていく
- ラスボス守護神に阻まれる
- 「あと少しだった」が次の1プレイにつながる
- まさかのサヨナラ勝ちを決める

という短いゲームの中のドラマを大切にしています。
