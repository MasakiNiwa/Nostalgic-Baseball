# Nostalgic Baseball ⚾

昔のブラウザミニゲームのような、シンプルで気軽に遊べるタイミング野球ゲームです。

現在は「9回裏の大逆転劇」をテーマに、普通ならひっくり返せないような大差から、3アウトになるまでどこまで追い上げられるかを楽しむゲームになっています。

## 🎮 ブラウザで遊ぶ

**GitHub Pages:** https://masakiniwa.github.io/Nostalgic-Baseball/

インストール不要です。スマートフォン / PC のブラウザからそのまま遊べます。

## 遊び方

1. 「ゲーム開始」を押します。
2. 9回裏、**8〜12点ビハインド**からスタートします。
3. 投手の動きとボールを見て、振るか見送るかを判断します。
4. タイミングを合わせてヒットや長打を狙います。
5. ただし、バットに当たっても凡打や併殺になることがあります。
6. 3アウトになるまでに、できるだけ点差を詰めます。
7. 相手の得点を上回れば、まさかの **逆転サヨナラ勝ち = GAME CLEAR** です。

サヨナラは簡単には起こりません。

このゲームでは、

- 何点返せたか
- 最終的に何点差まで迫れたか
- 同点まで追いつけたか
- ポイントをどこまで伸ばせたか
- 本当にサヨナラまでひっくり返せたか

という段階ごとの成果を楽しめます。

### ゲーム終了時の評価

- **GAME CLEAR / 伝説のサヨナラ**: 大差を本当に逆転
- **CLEAR目前 / 奇跡の同点**: 同点まで追いつく
- **超猛追**: あと1〜2点まで迫る
- **大反撃**: 大きく点差を縮める
- **NEXT CHALLENGE**: 次の挑戦へ

ポイント制と自己ベストもあるため、サヨナラできなくても毎回のプレイに記録が残ります。

## 操作方法

- スマートフォン: ゲーム画面をタップ、または「スイング！」ボタン
- PC: ゲーム画面をクリック、「スイング！」ボタン、または Space キー

## カウントと見極め

ゲームにはボール / ストライク / アウトのカウントがあります。

特に **フォーク** は打者の手前で大きく落ちるボール球として登場します。

- 振る → 空振りストライク
- 見送る → ボール
- 4ボール → フォアボールで一塁へ
- 3ストライク → 三振で1アウト

球種は投球中には表示されず、投球結果が確定したあとに公開されます。

## 凡打と併殺

v0.5では、バットに当たっても必ずヒットになるとは限りません。

- タイミングが少し外れる → **凡打** で1アウト
- 一塁走者がいる状態で凡打 → **併殺** になる可能性あり
- 良いタイミングでも、一定確率で野手の正面に飛ぶことがあります

「打った！」と思った直後にアウトが増える、少し理不尽な野球らしさを追加しています。

## 投手交代：先発 → 中継ぎ → FINAL BOSS

### 1. 先発投手

ゲーム開始時の投手です。

ストレート、チェンジアップ、ツーシーム、カーブ、フォークを投げます。

### 2. 中継ぎエース

先発から **3連打** すると投手交代。

中継ぎエースが登板し、難易度が一段上がります。

- 球速アップ
- スライダー追加
- フォーク率アップ
- 打球が凡打になる確率アップ
- ヒット判定が少しシビアに

### 3. FINAL BOSS 守護神

中継ぎエースを攻略し、本当に逆転が見えてくると登場します。

目安は、

- 3点差以内まで迫る
- 塁上の走者を含めて同点圏が見える
- 大量点差から大きく追い上げる

といった状況です。

守護神は完全なラスボスです。

- 164km級の剛速球
- 高速スライダー
- 消えるフォーク
- タイミングを崩す超遅球
- フォーク比率が高い
- ヒット / ホームラン判定が極端に狭い
- 良い当たりでも凡打になる確率が高い

「ここまで来たのに勝てない！」を狙った難易度です。

## 塁状況

ゲーム画面右上にダイヤモンド表示があり、一塁・二塁・三塁の走者を確認できます。

- ヒット: 走者が1つ進塁
- ツーベース: 走者が2つ進塁
- ホームラン: 全走者と打者が生還
- フォアボール: 必要な走者が押し出される

満塁からの長打、押し出し、併殺、大量点差からの猛追など、短いプレイの中でも展開が変化します。

## このゲームで目指しているもの

2000年代ごろによく見かけた、説明を読まなくてもすぐ遊べる小さなWebゲームの感覚を、現代のブラウザで気軽に楽しめる形にすることを目指しています。

複雑な操作よりも、

- ボールを見る
- 振るか見送るか一瞬で判断する
- タイミングを合わせる
- 当たったのにアウトになる
- 走者がたまって緊張感が増す
- 好調になると投手が強くなる
- 大量点差を少しずつ詰めていく
- ラスボス守護神に阻まれる
- 「あと少しだった」が次の1プレイにつながる
- まさかのサヨナラ勝ちを決める

という短いゲームの中のドラマを大切にしています。
