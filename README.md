# Nostalgic Baseball ⚾

昔のブラウザミニゲームのような、シンプルで気軽に遊べるタイミング野球ゲームです。

現在は「9回裏の大逆転劇」をテーマに、普通ならひっくり返せないような大差から3アウトになるまでどこまで追い上げられるかを楽しむゲームとして開発しています。

## 🎮 ブラウザで遊ぶ

**GitHub Pages:** https://masakiniwa.github.io/Nostalgic-Baseball/

インストール不要です。スマートフォン / PC のブラウザからそのまま遊べます。

## 遊び方

1. 「ゲーム開始」を押します。
2. 9回裏、**8〜12点ビハインド**からスタートします。
3. 投手の動きとボールを見て、タイミングを合わせてスイングします。
4. ヒットや長打、四球で走者を進めます。
5. 3アウトになるまでに、できるだけ点差を詰めます。
6. 相手の得点を上回れば、まさかの **逆転サヨナラ勝ち = GAME CLEAR** です。

サヨナラは簡単には起こりません。

このゲームでは、

- 何点返せたか
- 最終的に何点差まで迫れたか
- 同点まで追いつけたか
- ポイントをどこまで伸ばせたか
- 本当にサヨナラまでひっくり返せたか

という段階ごとの成果を楽しめるようにしています。

### ゲーム終了時の評価

- **GAME CLEAR / 伝説のサヨナラ**: 大差を本当に逆転
- **CLEAR目前 / 奇跡の同点**: 同点まで追いつく
- **超猛追**: あと1〜2点まで迫る
- **大反撃**: 大きく点差を縮める
- **NEXT CHALLENGE**: 次の挑戦へ

ポイント制と自己ベストも残しているため、サヨナラできなくても毎回のプレイに記録が残ります。

### 操作方法

- スマートフォン: ゲーム画面をタップ、または「スイング！」ボタン
- PC: ゲーム画面をクリック、「スイング！」ボタン、または Space キー

## カウントと見極め

ゲームにはボール / ストライク / アウトのカウントがあります。

特に **フォーク** は打者の手前で大きく落ちるボール球として登場します。

- 振る → 空振りストライク
- 見送る → ボール
- 4ボール → フォアボールで一塁へ
- 3ストライク → 三振で1アウト

球種は投球中には表示されず、投球結果が確定したあとに公開されます。

## 守護神

ヒットを3本続けると相手ベンチが投手交代。

**守護神** が登板し、ゲーム難易度が上がります。

- 球速アップ
- フォークの割合アップ
- 高速スライダー追加
- ホームラン / ヒットのタイミング判定がシビアに

大量ビハインドを追い上げ始めたところで守護神が現れるため、そこからさらに緊張感が上がります。

## 塁状況

ゲーム画面右上にダイヤモンド表示があり、一塁・二塁・三塁の走者を確認できます。

- ヒット: 走者が1つ進塁
- ツーベース: 走者が2つ進塁
- ホームラン: 全走者と打者が生還
- フォアボール: 必要な走者が押し出される

満塁からの長打や押し出し、大量点差からの猛追など、短いプレイの中でも展開が生まれるようにしています。

## このゲームで目指しているもの

2000年代ごろによく見かけた、説明を読まなくてもすぐ遊べる小さなWebゲームの感覚を、現代のブラウザで気軽に楽しめる形にすることを目指しています。

複雑な操作よりも、

- ボールを見る
- 振るか見送るか一瞬で判断する
- タイミングを合わせる
- 走者がたまって緊張感が増す
- 好調になると強敵が出てくる
- 大量点差を少しずつ詰めていく
- 「あと少しだった」が次の1プレイにつながる
- まさかのサヨナラ勝ちを決める

という短いゲームの中のドラマを大切にしています。
